# 미니 던전 카드

에너지 관리와 덱 성장에 초점을 맞춘 미니 로그라이크 카드 배틀 게임입니다. 한 턴에 여러 장의 카드를 이어서 사용할 수 있고, 전투가 끝날 때마다 보상 카드를 추가하거나 건너뛰면서 덱을 조정할 수 있습니다.

## 프로젝트 개요

- 장르: 로그라이크 카드 배틀
- 목표: 5개 스테이지를 돌파하고 마지막 던전 보스를 처치
- 핵심 재미: 에너지 분배, 카드 사용 순서, 보상 선택, 덱 압축 판단

## 주요 구현 내용

- 에너지 시스템
  - 매 턴 에너지 3으로 시작
  - 카드마다 비용이 다르며 에너지가 남아 있으면 계속 사용 가능
  - 직접 `턴 종료`를 눌러 손패를 아끼는 선택 가능
- 적 행동 구조
  - 슬라임, 고블린은 순차 패턴 유지
  - 박쥐, 오크, 보스는 `weighted_random` 방식으로 행동
- 보상 시스템
  - 전투 승리 후 보상 카드 3장 중 1장 선택
  - `보상 받지 않기` 선택 가능
  - `현재 덱 보기` 오버레이로 현재 카드 구성 확인 가능
- 전투 피드백
  - 피해, 회복, 중독 수치 float-up 연출
  - 플레이어 피격 shake 연출
  - 체력바 부드러운 전환
- 추가 보상 카드
  - 가시 갑옷
  - 흡혈
  - 과부하
  - 정화
  - 흉내

- 흉내

## 전투 흐름

1. 턴 시작 시 카드를 뽑고 에너지를 회복합니다.
2. 플레이어가 에너지 안에서 원하는 순서로 카드를 사용합니다.
3. 에너지가 모두 소모되거나 직접 턴을 끝내면 적이 행동합니다.
4. 턴 종료 시 중독 피해를 처리합니다.
5. 적을 쓰러뜨리면 보상 화면으로 넘어갑니다.

## 구조

`src/game/engine.ts`에 전투 규칙을 모아 두고, React 화면은 엔진 상태를 읽어서 렌더링만 하도록 분리했습니다.

- `src/game/types.ts`: 전체 상태와 카드/적 타입 정의
- `src/game/cards.ts`: 카드 데이터 정의
- `src/game/enemies.ts`: 적 데이터와 행동 패턴 정의
- `src/game/engine.ts`: 전투 진행, 카드 처리, 보상 선택 로직
- `src/components/*`: 시작, 전투, 보상, 결과 화면과 패널 UI
