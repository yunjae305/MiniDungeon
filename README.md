# 미니 던전 카드

시드 기반 절차적 맵, 상태 이상, 유물 시너지, 적 행동 의도를 묶은 미니 로그라이크 카드 배틀 게임입니다. 플레이어는 전투 전에 다음 노드를 고르고, 전투 중에는 적의 다음 행동을 미리 보면서 손패와 에너지를 배분합니다.

## 프로젝트 개요

- 장르: 로그라이크 카드 배틀
- 목표: 5층 던전의 마지막 보스를 처치
- 핵심 재미: 경로 선택, 상태 이상 누적, 유물 시너지, 턴 단위 퍼즐 풀이
- 배포: https://mini-dungeon-delta.vercel.app/

## 주요 구현 내용

- 상태 이상 페이즈 처리
  - 중독은 턴 종료 페이즈에서 피해를 주고 스택이 1 감소합니다.
  - 취약은 다음 피해 계산에 1.5배를 적용하고 턴 종료 페이즈에서 감소합니다.
  - `src/game/engine.ts`에서 전투 시작, 턴 시작, 적 행동, 턴 종료를 단계별로 분리해 처리합니다.
- 유물 시스템
  - 독니 부적, 사냥 증표, 전투 토템, 잔불 반지 유물을 구현했습니다.
  - 유물은 중독 추가, 취약 대상 추가 피해, 전투 시작 방어도, 조건부 턴 시작 방어도처럼 지속 효과를 제공합니다.
  - 엘리트 전투 승리와 상점 구매로 유물을 획득할 수 있습니다.
- 적 행동 의도와 페이즈 AI
  - 모든 적은 다음 행동을 정확히 보여주는 패턴 배열을 가집니다.
  - 일부 적은 체력 비율에 따라 페이즈가 바뀌며, 보스는 저체력에서 `파멸의 강타` 패턴으로 전환됩니다.
  - 전투 화면에서 행동 종류, 수치, 현재 페이즈를 함께 보여줍니다.
- 시드 기반 절차적 맵
  - 같은 시드를 입력하면 항상 같은 전투, 휴식, 상점, 엘리트, 보스 노드 구성이 생성됩니다.
  - `src/game/map.ts`에서 노드 타입 배치와 연결 정보를 생성합니다.
  - 각 노드는 다음 층 분기만 열어 주므로 경로 선택이 런 전체 구성에 직접 영향을 줍니다.
- 노드별 진행 루프
  - 일반 전투: 카드 보상과 골드 획득
  - 엘리트 전투: 카드 보상, 추가 골드, 유물 획득
  - 휴식: 체력 12 회복
  - 상점: 카드 20골드, 유물 40골드에 구매

## 구조

- `src/game/types.ts`: 게임 상태, 노드, 카드, 적, 유물 타입 정의
- `src/game/cards.ts`: 시작 카드와 보상 카드 데이터
- `src/game/enemies.ts`: 적 페이즈와 행동 패턴 정의
- `src/game/relics.ts`: 유물 데이터 정의
- `src/game/map.ts`: 시드 기반 맵 생성 로직
- `src/game/engine.ts`: 전투 페이즈, 노드 진입, 보상, 상점, 휴식 처리
- `src/components/*`: 시작, 맵, 전투, 보상, 휴식, 상점, 결과 UI
